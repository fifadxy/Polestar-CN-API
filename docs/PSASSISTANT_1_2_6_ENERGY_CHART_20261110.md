# PsAssistant 1.2.6 · 行驶与能耗费用统计图表优化

**2026-11-10** · versionCode **171** · 仓库 `fifadxy/Polestar-CN-API`

## 本次更新

1. **能耗图切换按钮防重叠**：选中态橙色背景向控件内收，选中与非选中边框统一 1dp，增加四周视觉留白；标签单行、超长省略，避免缩放字体时相邻高亮颜色贴合。应用的其他按钮样式不受影响。
2. **X/Y 坐标优化**：X 轴按天、周、月显示更多日期刻度（根据可用宽度自动控制密度）；Y 轴增加 0/25/50/75/100% 五级刻度、细网格线与单位。四类指标（行驶能耗／驻车空调／行驶里程／能耗费）均按对应数值与单位显示。
3. **柱顶引线与实际数值**：每个有实际历史采样的柱子可显示橙色引线和精确数值。默认只标注**最新有效柱**，点击图表中任意有效柱可查看／隐藏该柱数据；「数值·最新 / 数值·全部 / 数值·隐藏」按钮可循环切换。查看全部数值时自动扩展图表宽度，横向滚动避免标签相互重叠。
4. **数据口径与安全**：仅标注有实际本地采样的数值；无采样的日期保持空缺，不能填充为零，也不虚构费用。图表背景试验仍采用 VI 配色，车况获取、远程车控、OPPO Bridge 和中国区独立登录逻辑保持不变。
