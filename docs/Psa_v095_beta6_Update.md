# Psa v0.9.5 beta6 更新

2026-10-29，版本101，基于beta5。

- 三个主页面切换复用同一背景容器和WebView，只更换前面的原生界面；同坐标不重新加载网页。二级页面返回、前后台恢复只恢复WebView，不重新定位。参数相同不重置地图缩放或触发resize。该复用适用于同一Activity/App进程，进程被系统终止后仍须重新加载页面。
- 自动停车位置读取按现有map_refresh_minutes（默认15分钟，0为仅手动）计算，按上次成功获取的时间恢复计时，后台不保留刷新定时器；手动点击定位入口仍主动刷新。首次冷启动原3s/5s探测规则保留，不因普通前后台切换重复执行。
- 保留真实地图点位标记，替换为VI橙色图钉；删除原生橙色小圆点。隐藏路况、卫星等网页控件，保留地图署名。延迟出现的标记用单一、短延迟合并的DOM观察处理，无原生高频轮询。
- 车辆视角/颜色选择文字增大，日间纯黑、夜间白色，选中项用“已选”表述。默认PS皮肤SOC百分比明确加粗，不更改其他数据粗体偏好。
- 修复已复现的两条能耗闪退：Chart在条件表达式中对null SOC自动拆箱，以及没有历史车辆标识时调用vehicle.equals。图表显式保留可空数据，未知不补为0；无历史/当前无有效TM正常显示提示，不清空数据库。历史车辆选择的数据库错误也受控处理，保存状态索引限幅。

验证覆盖同一WebView跨三个页面/暂停恢复不替换、位置刷新剩余时间/仅手动规则、默认SOC粗体与日夜图库颜色，以及上述两种能耗崩溃场景。背景JS检查参数不变不触发resize、图钉VI颜色及路况控件整理。

未新增真实账号、实车和手机WebView验收。高德网页DOM和设备兼容性仍需实机复测；只读定位的自动时序可受系统后台限制和网络影响。完整APK从先上传的源码本地编译，保留原证书、客户端配置和车辆图资源；私有参数/签名密钥/用户数据不提交公共仓库。
