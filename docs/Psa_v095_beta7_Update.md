# Psa v0.9.5-beta7 · 外观控制与地图复用

版本102。基于beta6，保留独立登录、原签名、图片和历史数据。

- 设置→外观与交互→数字粗细/按钮背景透明度：PS默认电量与续航字重300–900，默认700。Android 8按系统字体档位兼容；Android 9+使用字重API。
- 全皮肤按钮背景不透明度0–100%，默认100%；只改背景Drawable，不淡化图标与文字。透明背景时可按个人背景调节可读性。
- 皮肤选择不再recreate Activity，复用既有停车地图/WebView；坐标和地图参数不变时不重新加载、不触发车辆定位读取。
- 仍按原地图刷新规则或用户手动定位刷新。进程被系统回收后需重新创建地图。

本轮提供自动化回归，不宣称手机高德网页或实车端到端已验证。
