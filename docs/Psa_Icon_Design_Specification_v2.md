# Psa 图标设计规范 v2

2026-10-27。用户已授权将“最新确认稿 · App黑白昼夜与通知栏”用于项目。此规范覆盖历史黑武士/星形App图标约定；不是官方源矢量资产声明。

唯一几何母版是 `branding/android/icons/Psa_Car_Master_v2.svg`。保留车顶、肩线的轻微弧度、线框粗细、双横灯和单层底部凹口。相同图形仅改变前景色，禁止给不同昼夜版重新生成造型。日间#202020 / #F5F5F7，夜间#FFFFFF / #000000。无渐变、光效或装饰边框。App自适应层18%留白，车辆比例固定；不预裁成圆形。

通知栏使用相同母版的透明底单色alpha资源 `ic_notification`，绝不把黑白背景或示意文字放进小图标。由系统决定深浅着色，不强行在白色状态栏画白底图片。Android13+启动器使用同一monochrome层；旧桌面可能缓存图标，系统昼夜限定资源不保证所有OEM立即重载。不新增图标切换常驻服务。

App标题、车控导航和Widget应用标识复用母版。车辆数据导航保留最新分支的列表图标，不覆盖他人的更新。

门锁锁定/解锁使用不同ic_lock/ic_unlock；尾箱复用同族锁图形，按已关闭/已打开状态切换，但仍标注尾箱，指令不改成门锁命令。未知状态不冒充解锁。车况、露营按钮都不带icon，尺寸和权重一致；正常/警告/激活颜色反馈保留。

车况按钮只显示一条“保养周期”参考剩余比例及进度条：min(剩余天数/365, 剩余公里/30000)，缺失一项用另一项，全部缺失不画比例；值限制0–100。完整剩余工时/天/km在详情保留。参考比例不等于后台原生寿命百分比。

寻车为菜单名称，内部“鸣笛/闪灯”保留具体动作含义。控制仍直接进入生物验证，取消不发送；无自动写重试。


## v0.8.5 交互补充

车况入口统一为页内目的地，二级区用独立箭头行展开/收起；异常/已报告值优先，未知折叠。车况/露营主按钮继续无icon、等大；设置7组采用同一展开组件与震动偏好。图标几何及昼夜配色不变。


## v0.8.6 显示与刷新约定

新增[UI与刷新规范](Psa_v086_UI_Refresh_Specification.md)：完整图标/标题组居中，反馈单独受边界约束；PS默认车况复用导航图标，窗/寻车复用既有VI图标。Widget provider与选择器预览同App启动图标。车况参考百分比可关闭/仅文字与百分比，露营保留无图标。充电卡允许专用慢速流光，其余不增加动态背景。


## v0.8.7 当前增量 · 2026-10-28

当前用户要求覆盖历史无图标约定：PS默认窗/车况/露营/寻车使用共同顶部图标槽（通常18dp，短横屏12dp）与原生文字/反馈基线；底部设置使用ic_settings六角环矢量。母版App/通知几何不变。点击车辆打开二级车况弹窗，车况按钮保留完整详情。All Good！允许6400ms文字流光，light_effects及all_good_shimmer可关闭，省电/隐藏/暂停停止；Widget保持静态。


## v0.8.8 当前增量 · 2026-10-28

最新用户三款图标要求由[Psa图标规范v3](Psa_Icon_Design_Specification_v3.md)覆盖；v2仅保留历史。当前App可切换三款，均有昼夜与单色状态栏；功能按钮语义不变。
