# Psa 图标设计规范 v3

2026-10-28。依据用户最新三款图标参考，替代v2的唯一黑白造型约定。原v2保留历史记录。本次是依据参考重绘的工程矢量，不声称为官方源资产。

## 三款形状

| 方案 | 日间 | 夜间 | 状态栏 |
| --- | --- | --- | --- |
| 车辆轮廓（默认） | #292B2D线条 / #F5F5F7底 | #E9EDF2线条 / #111214底 | 同轮廓，透明底白色alpha |
| 红色车辆 | #E60000车身 / 浅底，深色灯带 | #FF2424车身 / 深底 | 同剪影，灯带镂空，透明底白色alpha |
| 防滑图形 | #F59E00 / 浅底 | #FFA000 / 深底 | 车辆与双S形轨迹，透明底白色alpha |

三款只代表程序外观，不代表车辆故障、告警或防滑系统激活。手机UI警告颜色、功能按钮语义与既有VI规则不变。通知小图标不能可靠保留红/橙色，由Android按状态栏深浅着色，禁止把整张预览或方形底色当作小图标。

## 几何与构建

母版位于[branding/android/icons/v3](../branding/android/icons/v3)，每款有day/night/status SVG。Android路径与SVG由同一[生成脚本](../scripts/generate_app_icons.py)产生，后续几何修改必须改生成源并同时重建；不对昼夜版分别重新生成造型。200×200视口、曲线肩线、同族镜面/灯组；防滑图形与轨迹整体等比缩放。

自适应前景22%留白，实际像素位于108dp前景的中心66dp圆安全区内；无渐变、发光边框或预裁圆。Android26+提供adaptive-icon，Android33+提供独立透明单色monochrome层。状态栏版不含安全区的额外背景。Android主题图标可能接管红/橙颜色。

## 切换与生命周期

设置→外观与交互→程序与通知图标，可选三款及跟随系统/日间/夜间。九个稳定activity-alias仅切换启动器入口，真正MainActivity始终启用，固定包名和签名不变。Android33+批量原子变更，旧版本先启用目标再关闭其他入口，均使用DONT_KILL_APP；不额外申请权限、安装包或清除会话。取消不保存。进程启动及开机/升级恢复选择，无图标轮询服务。

跟随系统用values-night资源。部分OEM桌面缓存日夜/图标，需要返回桌面后稍候；不承诺所有启动器立即重载。App内部品牌标识、车辆控制导航、通知及Widget内标识使用同款形状。系统Widget选择器的静态应用标识仍为安装包默认轮廓，无法通过普通API动态改receiver图标；实际Widget内容跟随选择。
