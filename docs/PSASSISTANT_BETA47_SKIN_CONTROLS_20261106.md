# PsAssistant v1.0.0-beta47 / 161 — 净化读数与各皮肤按钮布局

更新时间：2026-11-06；基于 Beta46 Android 主线，保留 Stable / NEW / Mock LSPosed / CarLink 路径。

## 1. 功能变化

**净化按钮**：在空气净化未运行时，不再显示「已关闭」或「Off」文字，改为显示真实车况返回的 **AQI** 和 **PM2.5**。未取得有效测量值时显示 `--`，不能使用模拟数值冒充车况。净化正在运行、远控发送中或待确认时保留对应状态与倒计时；用户选择隐藏反馈或极简隐藏文字时遵循原设置。主屏按可用空间在同一行、两行或 NIO 独立 AQI 位置显示。

**皮肤按钮布局**：在 `设置 → 皮肤与外观 → 各皮肤按钮布局` 中，先选皮肤，再单独选门锁/空调/净化/尾箱/车窗/寻车/露营/保养按钮。7 套皮肤之间、8 种按钮之间均独立保存，不串改。每个按钮可设置：

| 属性 | 范围 | 默认 |
|---|---:|---:|
| 按钮边框宽度 | 60–100%（原网格比例） | 100% |
| 按钮边框高度 | 60–100%（原网格比例） | 100% |
| 边框线条粗细 | 0–6 dp | 保持原风格，单独保存后以设定为准 |
| 圆角 | 0–28 dp | 保持原皮肤风格 |
| 图标大小 | 50–190% | 100% |
| 文字大小 | 60–180% | 100% |
| 按钮位置 X/Y | 各 -24 至 +24 dp | 0 |
| 图文焦点 X/Y | 各 -24 至 +24 dp | 0 |

> 宽度/高度为原按钮所在网格中的比例，不允许占用相邻按钮的点击区。位置偏移被可用空白空间约束：宽高 100% 时，按钮无法左右/上下移动，先将宽/高调小才能移动。焦点偏移只移动按钮内显示内容，不改变实际点击热区。

所有新参数**默认完全复用旧版皮肤布局**。设置页提供离线实时预览、保存/取消、恢复当前按钮默认、恢复当前皮肤全部按钮默认。预览里的 `AQI 38 / PM2.5 12` 仅是用于展示排版的示例，实际车况页面绝不采用该预览数值。新参数进入设置备份白名单，但令牌、账号和车端鉴权数据不会备份。

## 2. 代码落点

- `SkinButtonLayout.java`：7 套皮肤 × 8 个按钮的布局数据、网格限制、视图应用、实时离线预览及默认恢复。
- `MainActivity.java`：皮肤/按钮选择、10 项滑块、槽位安装、净化展示专用布局；原按钮点击与车控验证逻辑保持不变。
- `ButtonFeedback.java`：净化停止时改为 AQI/PM2.5 反馈，远控待确认优先。
- `CenteredStatusButton.java`：原有标题加两项净化数值支持最多三行，不再截断第二项。
- `SettingsBackup.java`：精确新增皮肤控制参数的备份白名单。
- `button_appearance_ids.xml`：视图原始像素尺寸与文本缩放基准、每个控件 ID 标签。
- `Beta47AirIdleReadoutTest.java`、`Beta47SkinButtonLayoutTest.java`、`Beta47CenteredMetricsTest.java`：状态文本、缓存隔离、尺寸边界、三行内容等回归测试。

## 3. 验收

1. 默认皮肤、Simple、Simple2、NIO 等所有皮肤的原始尺寸与排列，在不修改设置时应与 Beta46 基本一致。
2. 净化关闭时只显示有效 AQI、PM2.5；不显示「已关闭」；缺失字段使用 `--`；运行/待确认状态不被读数遮蔽。
3. 任一皮肤的净化按钮设为宽 80%、高 90%、文字 125% 后，切换另一皮肤保持原值，切回恢复刚才设置。
4. 宽度和高度变小后，X/Y 位置在本控件槽位内移动，不能覆盖另一个按钮；图文焦点仅改变视觉位置。
5. 预览拖动滑块时显示即时变化，但点击取消不保存；点击恢复默认只清除对应皮肤或按钮。
6. UI 刷新、跨皮肤切换与设置恢复不触发远程车辆指令；原 LSPosed CarLink 模块与安全回读保持不变。
7. GitHub CI Android Debug 编译、Lint、主程序 + Bridge 单元测试通过。是否真机显示完美还需要 Android 17、不同屏幕字体缩放的视觉验收。

## 4. 交付与边界

Beta47 规划 `versionCode=161`。公开 CI 产物是 Debug 验证 APK；Standalone FULL 使用上一批准版的独立登录兼容资源，在**本地**与上一 FULL 相同的签名证书重新签名，不将客户端资源或签名密钥上传到 GitHub。

**APK 可安装与独立登录资源存在，不等于中国区账号实际登录成功或远程控车已在真车验证。** 本次变更仅涉及展示与设置，不修改车辆接口协议、账号授权和远控结果确认链路。
