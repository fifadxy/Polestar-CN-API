# Psa v0.9.5-beta9 · 排版与分层轨迹动效

版本104。基于beta8，保留默认皮肤/现有All Good显示选择、车图、独立登录与能耗记录。

## 外观与交互

All Good排版和字体从地图试验设置中移出，单独归类。
- 原默认下方位置与原单行默认不变。可选C方案：左侧All / Good!，车图缩小至76%、靠右下方，VI灰字在车后绘制。图片不变形；其他车辆视角保留原比例，按可用空间限位。
- 橙色All Good字重300–900，默认500；Android 8使用系统字体档位兼容。仅改文字粗细，不更改颜色、状态、指令。

## 动画、特效与测试

参数页按“总开关、充电、空调净化、四方向吸入、车窗、轨迹尺寸、界面动效”分组，可展开收起。旧偏好键保留。
- 空调/净化新增球型粒子，与现有充电粒子的实体圆芯/柔光外缘一致；选择球型时切换为吸入，也可继续选择穿透方向。
- 吸入由上下左右四边进入车辆图中心。范围50–250%；每边密度0–200%，0关闭该边。方向以车辆图片局部坐标为准，随顶视图旋转。
- 车后1/3、车前2/3粒子共享总预算，车辆原PNG负责遮挡后层；低内存机仍限制粒子数量。
- 气流尾迹以同一轨迹函数回采10段历史位置，透明度沿尾部递减；弧线扰动时尾迹沿真实曲线延伸，不再用头部切线画整根摆动直条。
- 制冷蓝、制热VI橙、净化绿、中性灰。配色仅为显示偏好，无可靠车端模式时不据温度猜测制热/制冷。

使用固定数组、缓存Paint/Shader，无逐帧随机和对象创建。后台、不可见、省电、系统关闭动画、独立开关仍遵循既有停播规则。自动化验证不替代真机帧率/耗电及实车验收。

验证：320项完整Release回归通过；最终布局/动效专项与C方案原生绘制检查通过。Lint无错误，仅保留既有19项UnusedResources。签名与私有配置由交付校验单独核对。
