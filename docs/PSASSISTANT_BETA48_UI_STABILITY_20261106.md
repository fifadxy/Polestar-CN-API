2026-11-06。基于 Beta47，沿用登录、车控回读及 OPPO Stable / NEW / Mock 桥接方案。

## 设置入口
- `设置 → 动画、特效与测试 → 长按触发时间`，默认 0.6s
- `设置 → 首页与车况数据 → 空气状态排版`，继续选择单行或双行
- 数据值显示只使用真实车况；预览示例不可作为车辆状态

## 针对二级菜单抖动的根因及方案
1. 旧版 `HapticDialogBuilder.create()` 在 `OnShow` 中重新应用字体、替换列表勾选标记、重设窗口背景，易导致弹窗出现后再次测量。现在改为显示前配置，列表适配器首次创建视图时就设置样式。仅保留 `OnShow` 首帧前的一次窗口几何校正，以防 Android 在 `show()` 时恢复 `WRAP_CONTENT`，不在显示后重新调整字体、背景和动画。
2. 旧版所有弹窗关闭窗口动画，并可能在显示后补偿视觉位置。现在窗口只做 alpha 0→1 的渐显，不再改变缩放、平移量。
3. 车况详情在数据刷新时会重建部分内容。现在滚动容器固定几何高度，让内容变化限制在弹窗内部，避免整窗重新居中。
4. 停车地图由 WebView 异步渲染，原先弹窗高度与地图内容存在耦合。现在对话框宽高固定、地图自身固定高度，动态加载仅影响内部内容。
5. 未实际运行 ColorOS 16/17 真机的帧时间、窗口 Insets 与动画追踪。若仍抖动，下一轮重点采集 `WindowManager` 尺寸、`ViewRootImpl` 首帧布局、OEM 自带窗口过渡以及软键盘 / 分屏 / 字体缩放边界。

## 验收
- 单击门锁与长按 600ms 不发生重复远控，滑动取消长按，600ms 前触摸抬起执行原点击。
- 皮肤排序 0.6s 后进入拖动，短按仍仅切换皮肤。
- 净化开启/待确认/关闭、缺失数据、深浅主题、4 按钮单行和双行、横竖屏、100%/130% 字号无文字错位。
- 打开并关闭各二级菜单 20 次，记录中心位置变化（目标进入后无跳动）与首次显示前后可测量的稳定高度；保留正常 alpha 渐显。
- 停车地图弹窗屏幕占用≤50%，内滚动操作仍可达，点击地图 / 刷新位置 / 手机位置权限均有效。
- GitHub Android Debug 编译、Lint、主程序与 Bridge 单元测试通过；最终稳定安装与车端命令需 Android/ColorOS 真机验证。
