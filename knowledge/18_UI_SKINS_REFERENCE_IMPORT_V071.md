# 18｜v0.7.1 三套 UI 皮肤与模板 APK 兼容导入

## UI 皮肤

设置 → 界面皮肤提供三套可持久化选择：

1. **最新模板**：延续此前确定的新版 Polestar 视觉方向，首页采用深色车辆主卡、橙色状态强调、浅色功能卡。
2. **当前版本**：完整保留 v0.7.0-beta1 的当前布局和交互，作为兼容基线。
3. **此刻图片风格**：依据用户 2026-10-26 提供的 EV 控制界面截图重做；采用浅色背景、大续航数字、车辆主视觉、四个圆形控制入口、状态条、充电卡和露营卡。

三套皮肤共用同一 VehicleCoordinator、China Session、车辆状态模型和强生物识别远控链路。换肤只改变呈现层，不改变 API、Token、远控字段或命令确认机制。

### 新规则

导入时验证：

- 包名必须为 \`app.c3garage.companion\`；
- APK 签名证书必须匹配已验证证书指纹；
- \`classes.dex\` 必须存在；
- 兼容材料候选必须唯一。

不再要求整个 APK 文件 SHA-256 与单一历史样本完全一致。第三方重新签名、包名不符或 DEX 结构异常仍会被拒绝。
