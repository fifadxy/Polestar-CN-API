# Psa v0.9.6-beta2 · 可选自动测试与窗口羽化

版本107，基于beta1。不添加纹理背景；保留原有门锁确认、图标、数据与独立配置。

- 动效自动测试支持勾选项目并保存，按所选场景生成循环；充电仍覆盖5种风格×2种方向，空调/净化覆盖两个方向。停止动效也可选；空选择不会启动循环。手动场景选择保留，所有测试仅在本机模拟。
- 修复测试页充电文字框与车图同层叠放的问题：流光卡片作为车辆区域下方的独立项，充电卡片与车辆可同时显示。页面切换测试也保留车图。
- 核查所有皮肤的实际充电布局，横屏/竖屏均验证文字流光框与车图不相交。充电卡片的流光仍只在卡片边界绘制。
- 地图背景的缩放范围从10–19扩展为3–20，模糊从0–24扩展为0–80，渐变外扩从20–100%扩展为0–300%。设置、初次URL与原位WebView样式使用相同范围；不因改参数重建地图或新增定位查询。实际缩放仍可能受地图服务限制，较大模糊参数的设备开销需实测。
- 车窗光效覆盖范围默认52%（仍可25–300%），增加边缘羽化大小0–100%，默认20%，0关闭羽化。新默认用于首次使用及恢复动效默认参数；已保存的明确选择不覆盖。
- 羽化采用向内渐变遮罩，不扩散至车身或车顶。几何距离场与遮罩缓存，最大384像素边长；只在尺寸/车型/参数变化时重算，不逐帧进行模糊运算。羽化关闭时保留原直接绘制路径。
- 空调默认球形粒子吸入，充电默认粒子吸入；已保存的直线/上升等选择保留，恢复动效默认可切换为新默认。通风与净化仍共用一个场景与同一逻辑。
- 自动测试选择和羽化参数纳入设置备份及默认恢复，其他功能与验证方式不变。

验证：343项Release回归通过，0失败/0错误；包含所有皮肤横竖屏充电区域、指定自动循环、默认值与偏好保留、缓存羽化边界。地图背景JavaScript检查含扩展极值及不重复重置；源码检查通过。Lint无错误，仅保留既有19项未使用资源提醒。真机WebView、帧率、耗电及实车验收未新增。
