# Psa v0.9.5 hotfix1 更新说明

2026-10-29，versionName `0.9.5-hotfix1`，versionCode 97。基于 Android 主线 `29d36b4`，本页取代历史中相冲突的回读、验证和设置说明约定。

## 界面与设置

- 所有皮肤的车况、露营按钮保留同风格图标、名称与小号灰色状态；简洁2补齐两处图标，按钮等高。保养比例不可用时显示已上报车况汇总；未知不伪装正常。车况和露营入口功能保留。
- 所有皮肤与原生Widget共用“电量指示条”开关，位于“首页与车况数据”；默认显示。关闭仅隐藏SOC横条，不隐藏电量数值、续航、充电数据或保养进度。
- 补充说明改为默认收起的 `?` 项，点击原位展开/收起；设置、选择弹窗、动效测试和能耗说明共用。输入标签、错误、删除确认及首次免责声明仍直接可见。
- 底部“车辆已连接/未连接”与发送/确认进度、结果共用一行，以 `·` 分隔。主名称白天黑色、夜间浅色，次要状态灰色。运行状态无可靠API字段时继续隐藏。
- 设置新增逐操作验证方式：生物识别（默认）、二次确认、直接发送。App和Widget共用15项操作策略；升级不默认放宽验证。选择列表可滚动，并立即显示更新后的策略。

## 指令与本机历史

- 最多5/10/15/18/26秒五个只读检查机会。首次新的有效LIVE回读匹配预期状态即结束；实验目标温度还需匹配新的目标温度上报。结束后取消后续排队读取，不自动重发写指令。
- 未确认期间再次点击同族按钮，先确认是否重发原指令；不会根据变化中的状态反向切换。取消不发出新写请求；确认后仍遵循该操作验证策略。其他控制族继续可用。
- 露营回读也在首次确认后结束；保留原电量下限、时长、检查间隔及停止流程。寻车缺少完成状态字段，只报告服务端已接收或未确认，不执行不能证明鸣闪结果的车况轮询。
- 能耗历史不再以当前在线或选中车辆为入口条件。可离线读取本机记录，必要时选择已保存车辆的脱敏记录；不发网络请求补造历史。当前TM实时估算仍要求有效的当前数据。

## 可调动效

设置 → 动画、特效与测试 → 车辆动态效果：

- 气流和充电吸入增加“弧线扰动/直线”开关，扰动默认开启；弧线粒子比例0–100%，默认20%。剩余粒子沿直线运动。
- 弧线范围0–100%，默认15%，以显示车辆的较短边为尺度；平滑确定性轨迹，无逐帧随机跳变。关闭扰动、比例为0或范围为0时均为直线。
- 颗粒大小25–300%，默认100%；同时调整气流粗细，保留清晰头部与渐隐长尾。
- 车窗内渐显光效强度0–100%（默认60%）、速度25–300%（默认100%）独立保存，不再与气流强度共用。
- 制冷蓝色、制热VI橙、净化绿色；真实API没有可靠冷/热字段时仍默认中性，用户选择视觉配色不代表改变车端模式。光效仅在对应功能运行且新鲜数据、可见、系统允许时播放；离线预览不发送车辆请求。
