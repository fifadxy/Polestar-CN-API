# PsAssistant v1.0.0-beta42 更新说明
2026-11-05 | Android | code 156

1. **二级菜单稳定性**：移除窗口缩放/位移及动态跨窗口模糊，抑制弹出时整体抖动；真实设备仍需验证。
2. **Widget VI**：空调、净化等开启时以 VI 橙色显示按钮图标，按钮背景使用轻量透明橙色。
3. **空气质量**：净化按钮下方默认 PM2.5 和 AQI，可设两者/单项/隐藏；NIO 版不改变布局。
4. **极简模式**：所有按钮名称、反馈与车况百分比隐藏，核心电池数据保留。每款皮肤独立设置简洁图标粗细/大小。
5. **默认皮肤排版**：第二数据列右对齐续航说明。
6. **停车位置**：停车点 c3Lbs 源数据与高德展示分离，智能15/30/60分钟自适应+失败退避，固定与手动可选；不附带车况读取。
7. **OPPO**：保留 Beta41 的 LSPosed 与 CarLink 接口，不把 Mock 或 Hook 探针视为真实绑定/控制验证。

## 构建与数据安全
公共 CI 的 APK 如缺失私有账号签名配置，则只是DEBUG验证包，不满足完整独立登录；不应覆盖已使用的原证书正式版。主 APK 和 OPPO Bridge 的 real-world 状态仍需设备测试。详见知识库 `knowledge/PSASSISTANT_V1_0_BETA42_UI_REFRESH_20261105.md`。
