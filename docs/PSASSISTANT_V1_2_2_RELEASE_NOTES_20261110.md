## 二级弹窗的抖动修复

统一在 `HapticDialogBuilder` 设置尺寸、居中和纯透明渐显样式；取消 `OnShowListener` 的显示后 `setLayout` / `setGravity`。所有二级弹窗（含停车地图）在首次 `onPreDraw` 前检查窗口属性，如平台覆盖了几何信息，则在**未绘制任何帧之前**修复，避免向左或向右晃动。软键盘改为 resize 适配，避免初始 pan。

## 质量控制与安全边界

- 新增状态文本、语言、中间态与尾箱上报测试；新增标准/紧凑弹窗的首帧稳定性测试；同步更新已有露营按钮测试。
- 按现有 GitHub Actions 执行 Android Debug 编译、Lint、单元测试和回归测试；验收真机实际弹窗是否仍有位置变化。
- **不更改** China Session、远程车控执行逻辑、OPPO Bridge 源码、LSPosed/Hook 及设备绑定；不提交密钥或私有客户端配置。
- GitHub Actions `VALIDATION-debug` 不含独立登录私有资源，仅为验证构建；如交付独立登录兼容 APK，须离线加入历史已批准资源并以原证书签名，再验证 APK 与版本号。
