# PsAssistant v0.8.5 beta1 · Widgets 5列及 PS 日夜配色

本次增量基于 feature/psa-v085-ui-fixes，不覆盖 Android 主分支。

- 桌面组件新增原生 **5×1、5×2、5×4** 三种尺寸，分别支持最多 4、8、12 个自选数据；它们使用独立的 AppWidgetProvider、组件选择器名称和各自的持久化指标键。
- 所有组件继续遵循自定义 Widget 字体颜色与“恢复 VI 默认”；更改 App 日夜主题后强制刷新已安装的组件。组件可在桌面调整大小，并依据实际分配的尺寸自适应。
- **PS 默认皮肤**：未知或关闭状态的车控按钮跟随主题白／黑／灰色板，不再将所有已知状态强制绘制成白底黑字；激活按钮统一 VI 橘色＋深色高对比图标／文字，图标与标签同步变色。
- 右上刷新图标保持无外框；车辆控制、车况、设置与系统通知的文本排版沿用此前 v0.8.5 修复。
- 新尺寸需要 Android Launcher 至少支持 5 列桌面栅格。5×1/5×2/5×4 是布局尺寸而非实际物理像素，最终大小由系统启动器控制。

验收：JDK17/Gradle8.7/SDK35 CI 的单元测试、Lint 和 assembleDebug；真正连接车辆、充电目标、Root/OEM Widget 排版等需要 Android 手机验证。
