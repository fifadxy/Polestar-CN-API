# PsAssistant 1.2.5 · 停车位置弹窗空间优化

版本：1.2.5（versionCode 170）  |  2026-11-10

## 本次变化

- **停车位置二级弹窗**：取消过去固定占用屏幕高度 88% 的设计，改为根据实际地图、工具栏、定位开关和关闭按钮内容自动决定弹窗高度，收起地图下方大面积留白。
- **地图本身保持原尺寸与交互**：保留直接拖动和双指缩放、缩放+/−、回到车辆、更新位置、坐标提示；外部「打开地图」继续作为小按钮保留。
- **小屏幕保护**：空间不足时才启用滚动容器，不强行压缩地图或裁切经纬度；弹窗继续在首帧前固定居中，采用原来的渐显动画。
- **测试**：覆盖日间/夜间、中文/英文、不同皮肤与屏幕，检查自动高度、地图可见性、说明和按钮不会被裁切。
- **安全及兼容性**：不修改中国区独立登录、车辆接口、车控指令、OPPO Bridge 或私有配置。本次 GitHub 只提交不含密钥的代码和说明。

## 交付验证

Android APK、Lint、单元测试与完整回归以对应 GitHub Actions 完成结果为准。仓库 CI 验证 APK 不包含私有客户端资源；独立登录兼容包如需交付，应使用此前已批准的本地资源和与历史版本相同的证书离线封装，再检查版本号及签名。
