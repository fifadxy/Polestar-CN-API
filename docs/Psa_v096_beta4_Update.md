# Psa v0.9.6-beta4 地图背景裁切与独立日夜模式

版本109，基于已同步GitHub的beta3。

- 地图背景改为独立固定裁切容器：保留同一个SDK地图节点，移出分享页原有父布局，避免父级缩放、底部卡片和未知网页兄弟节点进入背景。
- 背景只展示地图渲染层与停车标记，隐藏地图内部的非渲染控件；观察整个文档的后续节点插入，处理异步加载的浮层。地图来源logo与版权署名以小字号保留，不将它们误作停车详情删除。
- 关闭背景WebView的宽视口与概览缩放，统一以设备宽度计算等比铺满；标记焦点使用图标实际尖端，避免原生marker容器尺寸导致偏移。就绪检查须确认地图已放入裁切容器，未就绪不显示原网页。
- 新增“地图模式”：跟随系统、白天地图、黑夜地图。默认跟随操作系统日夜状态，与App皮肤的手动主题选择独立；地图日夜通过渲染层灰度/明暗处理实现，不引入Key或SDK依赖。
- 地图模式选择纳入设置备份/默认恢复。调整模式只原位重设地图外观，不重新查询车辆位置，也不因样式变化重设地图几何或缩放。交互式二级地图打开时也使用所选明暗模式。
- 保留此前定位点大小、颜色、焦点和粒子分层设置及所有车辆图片。

验证边界：Chromium离线仿真检查实际布局几何、未知及后加载浮层、焦点极值、横竖屏、日夜切换与同一地图节点复用。真实高德页面在当前环境的浏览器联网验收未完成，仍需手机端网络/WebView复测；外部网页改版或服务不可用也可能影响结果。
