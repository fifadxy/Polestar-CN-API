# Psa v0.9.6-beta1 · 设置与交互升级

版本106，基于v0.9.5-beta10，保留现有功能与数据。此次不添加纹理背景。

## 设置与显示

- 设置顶部搜索可检索已折叠分组，并直接进入真实设置项；支持常用中英文关键词。末尾新增更新记录、设置备份、恢复与全部恢复默认。
- 沉浸模式默认开启：背景延伸至状态栏，保留系统图标，交互内容避开状态栏/刘海；可以关闭。主页面、数据、动效、能耗等页面统一处理。
- 正常/异常车况文字分别自定义；支持最多80字与换行、行间距、横纵焦点、横向拉伸、大小、HEX颜色、粗细与打钩大小。默认VI橙色。文字和图标按可用空间限位；不改变正常/异常/未知的数据判断。
- 车辆长按1.1s打开选择菜单，两次触感更明显，继续尊重用户震动开关与强度。
- 所有皮肤的车况按钮与短按车辆共用二级车况菜单，保留主页，不切换大页面；底栏完整页面入口保留。
- 车况按钮默认仅显示保养百分比，不显示进度条；保留显式进度条选项。简洁/详细顶视布局默认使用顶视车图，明确选择的车图不被覆盖。
- 所有App皮肤新增统一文字加粗选项；原按钮、数据与Widget粗体选项保留。
- 动效入口统一命名“车辆动态效果设置与测试”。通风与空气净化合并为同一场景与参数逻辑。
- 充电流光：原版扫光 + 柔和呼吸、双向交汇、连续光波；支持1–30s周期、0–200%强度和自定义HEX颜色，默认VI橙色。

## 图标与通知

- 新增“确认稿 · 黑白车辆”图标，保留原图标选择。日间、夜间、跟随系统及透明单色状态栏资源均已加入；规范主稿为assets/Psa_Confirmed_Classic_Icon.svg。
- App图标与通知图标可以独立选择，也可让通知跟随App。仅为图形外观，和车辆状态无关。
- 常驻通知和“同时显示状态栏图标”独立设置。隐藏图标使用单独的最低重要度静默通道；系统仍要求合法小图标资源，部分厂商或系统通知设置可能保留图标，不能保证强制隐藏。
- 设置底部的更新记录使用人工整理的功能说明，不显示账号、凭据或品牌相关内容。

## 门锁与指令反馈

- 寻车菜单使用居中、有框线的宽按钮，方便双手操作。
- 长按门锁1.1s可独立选择上锁/解锁。默认生物识别；用户已有的逐项验证设置继续生效。短按仍按实际状态选择操作。
- 门锁/解锁在3/5/7/15s检查；7s这一轮读取完成仍未确认时，只补发一次原方向指令。绝不根据变化后的状态反转操作；确认成功、取消、退出或目标失效后不再开始后续检查/补发。正在进行的网络请求不能撤回。
- 其他指令保留原检查时序。百分比逐一递增，仅更新状态文字，不因此重绘全页；它是本机确认过程的展示，不是车端实际执行百分比。
- 确认成功立即显示结果；最终未确认显示“指令已发送，请确认执行情况”。寻车没有可验证的完成字段，继续区分已发送与效果未确认。

## 备份与恢复

JSON只备份允许的显示/功能偏好，不包含登录凭据、Token、车辆标识、历史数据库或本机图片。导入校验格式、键、类型和体积，确认后合并设置；恢复默认不删除登录与历史数据，也不发送车辆操作。通知常驻开关、系统权限与运行中的托管会话不通过备份迁移。

设备上的通知栏行为、真实指令与重发、帧率和耗电仍需实机验收。自动化结果不等同于实车成功。

验证结果：338项完整Release回归通过，最终22项交互/门锁/设置专项通过；Lint无错误，仅保留既有19项未使用资源提醒。源码结构与知识库一致性检查通过。签名、完整客户端配置与车辆图像由交付校验另行验证。
