# Psa v0.9.6-beta3 地图沉浸背景与粒子分层

版本108，基于beta2。

- 地图背景使用无边框WebView，关闭滚动条与越界滚动；背景专用样式隐藏分享页头尾、卫星/路况/缩放/定位等常见控件。二级地图预览保留原有交互。
- 地图容器以相同比例向四周扩展，并统一放大1.12倍铺满画面。移动整张地图及其标记，而非把停车点与实际道路拆开；保留服务来源标识。焦点边缘也留出裁切余量。
- 定位标记大小25–300%、十六进制颜色、横纵焦点0–100%可调。默认100%、VI橙色、50%/42%；模糊中心跟随焦点。无效颜色不保存；独立恢复标记默认。设置备份包含这些选项。
- 调整上述参数原位更新既有WebView，切换页面/皮肤不新增地图定位请求。仅使用车辆停车点，不新增手机定位授权或查询。加载失败安静退回主题底色。
- 充电、制冷、制热和净化粒子按大小稳定分层：用户选定车后比例中优先放大颗粒，车前保留较小颗粒，避免大颗粒遮挡车身。0%/100%等明确设置继续生效，密度/轨迹/粒径不变。
- 分层顺序仅在可见粒子数量变化时重算；前后共用粒子池，不新增逐帧对象、粒子数量或额外动画时钟。

地图依赖高德网页可用性及页面结构，未绕过服务要求。网页改版可能需要更新控件选择器；无Key页面无法保证所有设备/地区加载成功。尚未新增真机高德网页、实际帧率与耗电验收。
