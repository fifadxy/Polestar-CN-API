## OPPO 卡片自定义模板

默认模板：{soc}{sep}{range}；默认间隔为一个空格、中点、一个空格。支持字段：

- {soc} 电量；{range} 续航；{odometer} 里程；{updated} 最后数据更新时间
- {lock} 门锁；{climate} 空调；{air} 净化；{charging} 充电；{source} 缓存来源
- {sep} 自定义间隔；其他文字作为固定文案

常用示例：
- 88% · 370KM
- 88% / 370KM
- 88% · 更新 11-06 12:34
- 电量88% · 续航370KM

未上报字段自动省略，绝不补造 0 或假数据。模板限定单行、最多 160 个字符，并限制最终安全输出宽度不超过 40 个近似字符单元；仍不能保证在每种 OEM 宿主宽度下绝对不截断。模板字段禁止 VIN、Token、登录凭证等敏感项目。

设置路径：设置 → OPPO 系统兼容 → OPPO 负一屏 / 设备空间 · 卡片内容与实时预览。OPPO 系统兼容中心和设备卡诊断也有入口。预览仅使用本机缓存；没有缓存则明确标注样例值，不调用车端接口。保存会触发本机 Provider 的变化通知，部分 OPPO 宿主需重新进入卡片才更新。

## 验收

1. 验证 Provider DeviceModel、CAR 消息、AssistantScreen 和 MyDevices 本地卡片默认仅显示电量/续航；手机端 OPPO 宿主可达性以真机为准。
2. 编辑时实时预览；单字段、全字段、无值、异常值、自定义分隔符/文案、超长截断、安全字段白名单。
3. 车况异常显示具体项目；多异常优先显示重要项目，全部明细仍在车况页；字体不大于 14sp。
4. 指令确认后立即在命令栏显示具体结果，按钮和 Widget 以有效回读状态刷新，不出现最后的多余百分比；未确认继续按既有安全流程判断。
5. Widget Check 默认开，手动关闭后所有 Widget 隐藏；所有布局兼容，更新时间不重叠。
6. 自动编译、Lint、完整测试、APK 体积、签名与独立登录资产检查；Android/ColorOS 实机回归另行判断。

## Standalone FULL 独立登录交付条件

正式 FULL 需要批准的中国区客户端配置（或原可验证 FULL APK）、持久且与安装版本一致的签名密钥，以及适配实际 OPPO SDK 的打包配置。构建守卫仍要求正式客户端配置，不允许把敏感材料提交公开 GitHub。公开 Actions 只有 Debug 验证输入时，只能标记为 VALIDATION，**不能宣称独立登录 FULL**。真实手机号登录、Token 刷新、车况读取与车端指令回读仍须真机确认。
