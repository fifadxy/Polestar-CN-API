# Beta47 视觉与净化显示更新说明

**版本：v1.0.0-beta47（161）**

| 项目 | 更新 |
|---|---|
| 净化关闭 | 不显示“已关闭”，只显示 AQI 和 PM2.5；未知数值显示 -- |
| 七套皮肤 | 每套独立记忆按钮布局 |
| 八种按钮 | 门锁、空调、净化、尾箱、车窗、寻车、露营、保养 |
| 边框 | 各按钮独立设置宽高比例、粗细、圆角 |
| 文案与图标 | 各按钮独立设置大小，X/Y 定位与内容焦点 |
| 预览和恢复 | 离线实时预览、单按钮恢复默认、整皮肤恢复默认 |
| 系统逻辑 | 不影响现有车况、后台刷新、LSPosed 与远控安全验证 |

**设置入口：** 设置 → 外观与交互 → 各皮肤按钮布局。

技术约束与验收细节详见 [专项知识库](../knowledge/PSASSISTANT_BETA47_CONTROL_LAYOUT_20261105.md)。
