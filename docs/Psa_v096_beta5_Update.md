# Psa v0.9.6-beta5 地图来源与裁切焦点

版本110，基于beta4。

- 背景地图不再强制展示原图形logo；改为右下角一行小号“高德地图”来源文字与原版权信息，透明底色，日夜模式分别使用灰色文字。二级交互地图不改动。
- 新增独立“地图裁切焦点”横/纵设置0–100%，默认50%/50%。用于在既有定位焦点基础上偏移取景，每轴最大偏移视口的25%，最终焦点限制在画面内，避免裁切露底。道路、停车标记和渐变模糊中心一起移动，车辆经纬度不变。
- 定位标记大小/颜色/屏幕焦点继续保留；“恢复取景与标记”同时重置这两组设置。裁切焦点纳入设置备份与全部恢复默认。
- 调整取景使用同一地图/WebView，不新发车辆位置或手机定位查询，不重载地图，也不重设缩放。
