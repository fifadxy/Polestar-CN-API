# Psa v0.9.5 beta5 更新

2026-10-29，版本100，基于beta4。

- 新尾门线稿笔画由2.5增至4.2，旧车辆线稿2.8增至3.6。沿用原生主题着色和三款选择。
- 后方All Good改为大号重字体，支持单行“ALL GOOD！”或两行“ALL / GOOD！”。设置 → 外观与交互 → 地图背景 → All Good排版。字宽与显示区高度共同限幅，车图继续保持beta4的82%比例及下移；下方模式不变。
- 地图背景切换为硬件WebView直接渲染，移除软件Canvas截图及其位图缓存依赖。高德分享页使用WebGL，软件截图可能无法取得硬件图层，原截图流程无法保证可用。
- 背景直接使用高德官方免Key分享页，无新增SDK或第三方密钥。等待地图容器及canvas/瓦片元素，最多40次500ms检查；失败最多重载一次，最终提示不可用。仅网页导航成功不视为地图就绪。保持原位置权限约束，不请求手机定位。
- 以CSS对地图层做日夜着色、渐进玻璃模糊和控件整理，保留地图署名。App后台调用WebView暂停、恢复时重新检查；离开时销毁。直接渲染比单张快照更依赖WebView，但消除了抓图失败的必经环节；没有真机耗电结论。

验证：309项Release测试通过；背景样式Node检查通过，覆盖日夜、缩放钩子、玻璃参数及重复调用不堆叠节点。Lint无错误，仅19条保留的未使用资源提示。使用公开示例坐标访问官方URI，HTTP成功跳转到移动分享页，并确认页面使用WebGL；没有使用真实停车点。当前环境Chromium受代理证书信任限制，未完成真实浏览器画面验证，也未完成手机WebView或实车验收。地图是否实际显示、缩放、服务端限制及设备兼容性必须真机复测，不能把DOM就绪等同于地图像素已验证。

完整源代码先同步GitHub，后本地编译原证书独立APK。沿用已有登录配置、车控与露营恢复逻辑；私有参数、私钥、账号和车辆数据不上传公共仓库。
