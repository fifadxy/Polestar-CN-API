# v0.9.5 简洁2 气流与地图背景

2026-10-29，版本0.9.5-beta1 / 96。本增量优先于KB36中的18项测试、20fps节流、禁用R8及固定26秒完成的描述。

完整行为和边界：[Psa v095 更新与设计说明](../docs/Psa_v095_Update.md)。实际构建验证：[v095 验收](../docs/Psa_v095_Validation.md)。

简洁2为独立新皮肤；所有旧键、选图和皮肤索引保持。所有皮肤支持3秒长按车辆外观菜单，默认皮肤也可换图；13张车辆资源保持原像素。拖动皮肤顺序存skin_order。

气流吸入fx_air_direction、视觉配色fx_air_tint、车窗光fx_window_glow与原有气流/充电开关独立。无实车HVAC模式证据；热/冷配色是用户选择的视觉效果，不是API事实。模拟测试23项，真实运行状态仍由新鲜LIVE数据驱动。

CommandReadback在连续三次完整匹配后停止后续网络回读；实验目标温度也须匹配。没有重复车辆写操作。寻车仅确认发送，无法远程验证声光结果。自动数据刷新不显示顶部转圈。

停车点仍为c3Lbs；系统Geocoder免Key解析地名，缺失时显示坐标，无点显示“停车数据未更新”。不调用手机GPS。地图夜间为网页着色，背景试验默认关闭、临时截图/内存模糊，无GPS和连续地图刷新。高德分享页DOM变化可能影响显示，不能承诺无条件隐藏全部服务商元素。

Release采用保守R8，业务类全保留，不混淆，不改变车图质量；公共源码不包含私有客户端配置值和用户会话。原有私有输入加载方式继续适用。

连接栏：lastVehicleReadOk + 当前会话/车辆 + 15分钟内LIVE快照才显示“车辆已连接”，否则灰字未连接。连接不代表车辆长连接。运行状态没有可靠数据时隐藏：模板33字段无停车/行驶字段；Mac比较文档Availability/Dashboard仍为中国区MAPPING REQUIRED。不得用停车点、门锁、电源或平均速度推断当前行驶状态。
