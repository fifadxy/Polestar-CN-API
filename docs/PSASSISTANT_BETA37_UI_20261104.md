## 使用与验收

1. 覆盖安装固定签名 FULL 包；保留账号和偏好。
2. 底部点车况：应显示图1并变橙；各皮肤的小“保养”入口应显示图2，弹窗包含周期和检查。
3. 车图短按检查窗口大小，长按999ms不触发、1000ms触发外观菜单；滚动手势取消长按。
4. 依次长按锁、窗、尾门、空调和净化，确认可以明确选择相反方向或重新发送；取消不发送。
5. 设置→外观→字体、按钮图标与文字大小：拖动查看预览；取消、应用、默认分别核对。
6. 设置→动效：吸入范围最大800%，调渐变出现；在充电、空调、净化场景检查无矩形源和按压外框。
7. 小屏/横屏/大系统字号需要真机逐项检查触区和布局。CI编译、单元测试和预览不能替代手机与车辆验收。
