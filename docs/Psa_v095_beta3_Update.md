# Psa v0.9.5 beta3 更新说明

2026-10-29，版本98。整合Android主线29d36b4、另一位AI的beta2分支4d795e2和本地hotfix；本说明优先于历史版本中的冲突约定。

## 指令、会话与露营

- 首次有效LIVE状态匹配后结束回读，保留5/10/15/18/26秒最多五次只读机会；实验目标温度仍需独立匹配。寻车只报告服务端接受或未确认，不用无效车况轮询伪造鸣闪结果。
- 同类指令重复点击先确认，最多排队一次，当前指令核实结束后再发。其他控制族不被一并锁住。退出登录取消后续回读，旧会话请求不能重新写入令牌。
- 按15个具体操作设置生物识别/确认/直接发送，默认生物识别。使用独立偏好键，不把beta2的整类直接发送意外扩大为解锁授权。
- 保留beta2的本地露营立即停止、允许离线退出、加密保存待核实停止、同车新鲜回读后单次恢复停止及网络恢复监测；不保证断网时车辆已经停机。JobScheduler受系统限制。
- 能耗历史离线可读。所有皮肤车况/露营图标、名称与状态保留；App和Widget电量横条可隐藏。底部连接和指令状态以点号合为一行；说明默认收起在问号中。夜间主标签浅色，次要状态灰色。

## 背景与车辆交互

- 修复地图截图WebView透明导致部分设备不绘制的问题，保留正常绘制后再截取；拒绝纯色空白图，有限重试、22秒超时回退。
- 地图快照在本机缓存10分钟，按停车点/昼夜/缩放区分，最多保留8张；正常切页复用，不重复持续加载网页。日夜分别原生着色，外扩渐进模糊沿用可调参数。不读取手机位置。
- 高德背景缩放10–19；通过分享链接与可访问地图实例设置。免Key分享网页不是正式地图SDK，地图DOM、缩放是否被服务端采纳、设备WebView绘制仍需真机验证。未引入beta2的OSM/Topo自动外部回退。
- 设置中选择纯色、高德、本机图片背景。系统文件选择器仅访问选中的图片；本机拖动裁切、缩放、EXIF方向处理，日夜分别保存。取消选择不改变旧背景；导出图去除原始图片元数据。无云端上传、无相册全盘权限。
- All Good可选现有下方位置或位于车辆图层后方的大号VI灰色文字，默认沿用下方。异常不隐藏；充电期间仍优先充电状态。图层后方模式按选车视角居中，不承诺所有车型的精确物理尾部位置。
- 短按车辆：触感和轻微高亮，仍打开门窗二级菜单。按住时提示“长按1.5s选择车辆图片”，1.5秒后再次触感并打开外观菜单；滑动取消长按，不额外触发短按。

## 动效与图标

- 用户确认默认20%曲线、80%直线；范围默认15%。关闭扰动可全直线。颗粒大小25–300%，玻璃强度/速度独立可调。冷蓝、热VI橙、净化绿；未确认冷/热模式时不根据设定温度猜测。
- 尾箱使用用户确认的侧视车辆/抬升箭头线稿，Android矢量和SVG共用路径，日夜由主题着色，App/Widget同步。净化候选尚未确认，继续保留原图标。
- 保留13张现用车图原字节，不使用本轮失败的发光生成稿。后台、隐藏、省电暂停动效规则保留。

## 验证和交付

自动化结果以beta3最终验收记录为准；无本轮真实账号登录、授权车辆动作或真机帧率/耗电测试。完整APK在私有构建环境使用原签名和客户端配置，源码先同步GitHub，再本地编译与交付；公开CI缺Secrets时仍只是开发验证APK。
