# Psa v0.9.5-beta10 · 独立吸入场与柔化动效

版本105，基于beta9。按用户决定，不添加纹理背景。

- 充电、空调、净化分别配置吸入场：范围25–400%，上下左右密度各0–300%，车后比例0–100%（余量在车前），吸入焦点X/Y各0–100%。参数不互相修改；0密度关闭对应方向。焦点/方向均按车辆图片局部坐标计算，随车图旋转。
- 未调整的充电焦点继续使用原充电口；空调/净化默认车辆中心。只调整某一轴时，另一轴保留原默认。旧版共用吸入范围/密度作为空调与净化的初始回退值，旧偏好不会丢失。
- 充电也分车后/车前两层绘制，所有层共享固定粒子预算；低内存机保留限量。
- 气流尾迹长度10–300%，回采32段轨迹并渐隐。充电及空调/净化球形颗粒使用径向透明渐变边缘，加入进出场淡化，避免硬圆突现。
- 车窗覆盖范围25–300%、强度0–300%、完整渐变周期1–60秒。取消循环位置跳变，使用周期连续的缓动往返；始终裁定在原车窗轮廓中，不侵入车身。旧速度设置换算为初始周期。
- 设置保留beta9分类，独立列出充电、空调、净化的吸入与分层参数；恢复动效默认值覆盖新增参数。

上述仅为显示参数，不修改车端控制、空调目标温度、指令确认或登录规则。仍沿用制冷蓝、制热VI橙、净化绿、中性灰；无可靠API时不推断车端模式。未新增地图刷新或手机定位请求。
