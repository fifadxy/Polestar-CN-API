# PsAssistant v0.9.5-beta2 Hotfix · 2026-10-29

VersionCode 97. 基于 v0.9.5-beta1（96），仍为非官方独立 Android 客户端。

## 一、车控与身份验证
车控按 lock / climate / air / trunk / windows / signal / camp 七个家族独立等待。五个只读检查节点 5/10/15/18/26 秒，得到三次连续有效 LIVE 确认后提前结束，不继续显示后续进度。用户再次点击正在等待的同类按钮必须弹确认框；用户确认后至多排队一次重复发送，不在网络超时时自动重发。设置提供各类生物识别（默认）/二次确认/直接发送；直接发送依然要求用户主动操作、有效登录及首用授权。断网时不得伪造“执行成功”。

## 二、托管退出和网络恢复
本地结束托管立即同步写入 STOPPED、取消后续托管维持任务，不等待车端网络和认证。车端空调/净化状态单独保存在 remote_stop_pending 状态，用户能在离线或会话失效时退出本机登录。用户确认退出登录后清理本机加密令牌、取消本机任务，明确提示车辆空调可能仍运行，需车内或官方 App 再次核实。Android 网络恢复回调 + 持久 JobScheduler 将先读取最新 LIVE 车况；若确认停机则清除待核实，若仍开启则每个动作只尝试一次远程停止，发送结果未知时不自动盲目重复。正常托管恢复也必须读取新鲜电量和空调状态才决定维护操作。JobScheduler 受 Doze 限制，不能保证立刻唤醒。

登录令牌 Android Keystore 加密保存。仅在服务端允许时使用正式 refresh-token 接口，拒绝时要求交互重新登录；不绕过服务端有效期。登录与刷新在后台完成后有会话世代校验，用户退出后旧网络请求不能重新写回令牌。

## 三、UI 与历史
历史能耗页不再要求当前车辆在线；优先使用本地已选车型的哈希身份读取 SQLite 历史。单行状态条为“车辆已连接/未连接 · 指令状态/更新时间”，不宣称车端长连接。所有皮肤新增隐藏电量进度条开关（SOC 数值保留）。车况/露营按钮统一图标、文字和状态；夜间控制状态可用白色增强对比。说明集中到橙色圆圈 ? 按钮，点击查看。

## 四、动效与地图
充电五种 C1 风格、上升/吸入双方向不变；新增不规则曲线幅度 15% 默认、直线路径比例 20% 默认、粒子大小 25–300%、出现区域 30–150%，范围内渐显而非画面外突然进入。顶视车辆四周吸入车底，非顶视在车底与前脸区域视觉吸入；不是物理充电口坐标。A1/A2 气流复用扰动参数。车窗渐变强度、速度独立可调，制冷蓝、加热 VI 橙、净化绿；车端未提供冷热模式时采用中性显示，不用视觉颜色替代真实回报。

地图背景默认关闭，提供高德、OpenStreetMap、OpenTopoMap 三种可选公开网页来源、缩放10–19、模糊0–24和外扩20–100。修复透明度0导致 WebView 不绘制的问题，等待非空地图像素后再内存抓图，高德失败时一次性尝试 OSM。地图供应商可用性、版权署名和真机截图需单独核查。

## 五、测试与构建边界
测试成功与否以 GitHub Actions 对应最新 SHA 为准。公网 CI 只构建缺私有中国区客户端配置的 Debug 验证包；完整可独立登录、可同签名升级的 Release 需从已授权旧 PsAssistant APK / 私有配置恢复客户端兼容材料，并在安全私有构建环境使用原稳定签名。不得将私有签名、客户端参数、密码、Token 或 VIN 上传公共 GitHub。

验收重点：离线托管立即停止和退出登录、恢复连接先刷新、拒绝自动复写；同类操作二次确认而不同操作互不阻塞；历史离线可看；所有皮肤图标和电量条开关；地图失败不影响主页面；真实车辆最后仍需授权实车验证。
