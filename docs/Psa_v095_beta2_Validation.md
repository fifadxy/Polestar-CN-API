# v0.9.5-beta2 · 构建与验收

版本 97，包名 io.github.polestarcn.companion；Android 8.0+。基线 29d36b45。

## 回归清单
- 车控：同家族二次按键弹确认、最多一个排队重复，三次连续 LIVE 状态即可提前确认；不同家族可继续操作。
- 会话：退出操作立即清除本机令牌，即使刷新请求因断网未完成；失效令牌必须重新登录；不能绕过服务端策略。
- 托管：无网或 401 仍可本地 STOPPED 和退出登录；重连必须先只读验证，未知写入不能补发；工作队列因 Doze 可能延迟。
- UI：全皮肤按钮有图标/主标题/状态；夜间可读；电量条可隐藏；单行连接·命令状态；历史 SQLite 离线可读。
- 原生动效：5×2 充电组合、A1/A2 气流、路径曲率/比例/半径、车窗彩色柔光速度与强度；后台不持续帧绘制。
- 地图：Amap / OSM / Topo、缩放，WebView 可见抓图，加载失败回退及隐私、署名。
