# Psa v0.9.5 更新与设计说明

2026-10-29，versionCode 96，基于 Android 主线 ffb90ca。优先于历史动效、皮肤和指令回读约定。

## 界面与设置

- 新增“简洁2”：参照用户第三张图的电量/续航、橙色进度条、侧视车辆、双列控制卡片、舒适控制、车况/露营及基础数据区。保留全部控制和数据详情入口；首页展示优先三项，其余在车辆数据页。横屏及高度小于680dp的小屏使用原有紧凑结构。日夜模式均支持。
- 所有皮肤长按车辆3秒打开外观二级菜单；滑动或抬手取消未完成长按。短按仍打开原门窗/车况二级弹窗。PS默认不再强制覆盖用户选车，自动模式仍使用原白车。
- 皮肤选择卡片长按拖动排序；顺序持久化，不会改变当前皮肤。旧皮肤键值和索引不变。
- 设置分类：外观与交互、动画/特效/测试、首页与车况、Widget、车辆与定位、后台通知、手表预览、账户。选择项和开关有边框与正常触控区域；默认皮肤数据字体放大。修复车况按钮重复组合反馈造成多行标题、字体过小的问题。
- 充电时在原健康状态位置显示更大充电文字/流光，隐藏All Good，避免重复独立充电栏挤占位置。未充电时原健康状态恢复；没有删除车况入口。
- 三个主页面采用230ms左右滑入；原生弹窗220ms渐显/缩放，API31且系统支持时使用背景模糊，其他系统用半透明渐变玻璃模拟。无视频、GIF或额外图像库。

## 动效和资源

- 全部13张现用车辆WebP逐字节保留；本次候选重绘图不纳入APK。
- 气流改为清晰头部、连续渐隐长尾，制热VI橙、制冷蓝、净化绿；支持穿透与吸入，新增按视角玻璃多边形内的缓慢渐变循环光效。玻璃区域为人工视角遮罩，非车端精确窗体坐标。
- 真实中国区API仍没有可靠HVAC制冷/制热模式字段。默认运行空调用中性气流；用户可明确选择橙/蓝视觉配色，选择不代表改变车端模式。净化用独立运行状态。
- 离线测试扩展至23项：10充电组合、5穿透气流、5吸入气流及3种文字/页面效果。自动测试不修改用户已保存方向或风格。
- 车辆效果使用Choreographer随屏幕帧调度，移除原50ms固定节流；文字流光移除12/20fps更新节流。低内存机仍限制绘制量、约30fps绘制；隐藏、后台、省电或系统禁用动画时停止。没有真机FPS和耗电测试，不能保证所有设备不掉帧。
- Release启用保守R8/资源裁剪：保留全部应用业务类，不混淆，不优化业务代码；仅移除未使用依赖/资源，不改变车辆图像素。私有构建配置仍由原加载器生成。

## 指令进度与结果

保留5/10/15/18/26秒最多五个只读检查机会，不补发车辆写指令。连续三次LIVE状态匹配且实验目标温度要求也满足时，立即确认成功；剩余检查在入队和网络读取前短路，已在途请求不额外补发。不同控制族独立。失败/未知最多五次后结束。声光寻车没有可读取的完成状态，只显示“已发送/未确认”，不伪造成功。

界面简化为发送中、执行中百分比、执行成功或结果未确认。仅用户下拉/点击刷新的数据读取显示顶部转圈；启动刷新、周期刷新和指令回读保持安静。正常前后台周期规则仍保留。

## 定位与试验背景

- 首次连接后按本次打开的3秒/5秒时点尝试读取停车点，地名成功后停止后续尝试；如果车辆发现较晚，过期时点会尽快补尝试。无需手机GPS。系统免Key地理编码在独立线程解析，服务可用性依设备地区；失败显示经纬度，没有停车点显示“停车数据未更新”。名称和停车点仅驻内存，退出/换车清除。
- 地图二级页暗色模式对地图画布和底部面板作夜间着色；高德官方免Key分享页未提供可靠的统一夜间URI参数，因此不是高德SDK夜间地图。
- 默认关闭的高德地图背景实验：外观设置中开启，模糊0–24、外扩20–100%。只加载当前车辆停车点，不申请手机定位；高德网页完成后作一次最大640px宽的临时内存截图，后台计算渐进模糊，随后销毁WebView，无持续地图动画/轮询。地图颜色黑白化，视角定位点居中放在健康/充电栏上方，无文字说明。
- 实验模式通过CSS隐藏分享页的操作/距离/标记等控件。高德网页结构、地图加载或WebView不兼容时可能退回普通背景；实际地图样式、加载完成时机和控件隐藏仍需中国区真机确认。没有移除服务端原始地名、坐标或伪造地图。地图底图法定归属信息可能保留。

## 独立构建与隐私

仓库同步配置加载器和CI私有输入接入方式；完整APK本地注入原有客户端兼容参数并使用原证书，不含用户手机号、密码、Token、VIN或实际停车位置。私有参数/证书不写入公共仓库。GitHub Actions没有对应Secrets时仍只能产出开发验证包，不能把它称为完整登录版。签名参数不能从公共源码恢复。

## 常驻连接与运行状态栏

所有皮肤及三个主页面底部共用连接/命令栏：近期LIVE数据读取成功且有会话、选中车辆时显示“车辆已连接”（日间黑字、夜间浅字）；未连接、读取失败或数据超过15分钟时显示灰字“车辆未连接”。连接表示App可以读取近期车辆数据，不宣称车端持续在线。启动加载的本地缓存不构成连接证明。

运行状态用灰色小字单独显示。交叉核对模板33字段和Mac研究后，Availability/GetLatestAvailability、Dashboard/GetLatestDashboard只有服务名证据，中国区字段仍标记MAPPING REQUIRED，不能可靠显示停车/行驶。因此本版隐藏运行状态，不从门锁、充电枪、历史停车点或TA/TM均速猜测。后续需真实中国区响应验证才增加映射。

## 最终排版增量

VoLike各配色/详细模式的顶视图根据原始车头朝向选择正负90°旋转，统一车头向上；不重绘或改变车辆比例。停车位置摘要靠定位图标右对齐。寻车状态行默认显示灰色“鸣闪”。控制按钮主名称使用日间深色、夜间浅色实字，状态行始终灰色且小于主名称；小布局对状态字号作上限约束。底栏图标从19/21dp增加为23/25dp，约20%，点击区域不缩小。

最终规则：白天按钮名称为黑色实字，夜间为白色实字，保留深色按钮底；状态文字始终为灰色且字号更小。
