# PsAssistant v0.9.0-beta1 · 车辆图库与交互优化

**基于 v0.8.9 登录兼容版；版本号 91**。仅调整本地展示与外观设置，不修改中国区 API 认证/车控协议。

## 本次覆盖
1. 露营运行后，在按钮下方仅显示剩余时间；完整后台托管诊断仍在露营详情；不改变自动停止/低电保护。
2. PS默认皮肤车况与露营/车窗的文本字号对齐，保养百分比反馈尽量缩短。
3. 设置页的保养、磨砂、定位、手表预览说明改为点击“?”查看；主要开关及安全告警保留可见。
4. All Good！光效修复：增大可辨识高光，扩大适配文本形式；仍尊重电池节能/总开关。
5. Widget 文字颜色修复：跟随系统、白、黑、VI橙、北欧青绿、石墨灰、自定义HEX；所有风格统一使用配置。
6. Widget 图像：可换为程序图标、用户提供的黑白透明线稿或黑武士照片，不拉伸源图。
7. 首页车辆图库：白天/夜间独立；设置中先选视角（顶视、45°、正面、侧面），再选具体颜色/版本。保留源图片比例，白色顶视已经逆时针旋转为横向资源；默认皮肤白天白车顶视，夜间深色顶视。
8. 车辆信息新增“车辆规格”二级页面，显示经过核对的全球版规格索引，点击“官网完整规格”通过应用内 WebView 展示极星网页；不把全球车型配置标记为当前中国区车辆真实设备规格。

## 图库来源与限制
本次纳入用户当前可获取的车辆原图集，包括黑武士、透明线稿、黑/白顶视、正面、黑/白/蓝灰侧面；45°优先复用项目原有的车辆主视觉 `vehicle_hero.webp`。后续上传的其他45°颜色素材如未由会话提供可读取的二进制文件，则不能凭描述声称已经打包。设置分类支持扩展，不需要重构选择器。

## 构建与设备验收
公共 CI 的 Debug 包缺少私有账号配置，仅支持 UI、Widget、规格和 Demo 数据验证，不代表中国区登录通过。可登录完整包应复用此前可用完整 PsAssistant 的受控配置，并使用原发布签名。端到端车辆验证待真机检查。
