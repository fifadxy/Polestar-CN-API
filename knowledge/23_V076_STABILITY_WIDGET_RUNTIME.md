# 23｜v0.7.6 首页布局、Widget、倒计时与刷新修复

基于已成功构建并上传 APK 的 v0.7.5 `fa81ac5` 开发；详见 [Psa v0.7.6 更新说明](../docs/Psa_v076_Update.md)。

## 状态和来源

- 首页保持简洁/详细两套、一页显示、最多 12 项；同一套绑定函数负责局部更新，设置变化才重建布局。
- 主要数值与辅助标签分层；主控制状态必须保留文字空间，不能只通过外层按钮仍在屏幕内判定布局合格。
- `DisplayMetric.reportedAt` 对电池、里程、能耗、环境、Health 使用各自来源；缓存不会改变来源报告时间。
- Health 的玻璃水/12V：0=未知，1=明确正常，2=告警，未识别枚举保留未知。参考固定上游 proto；中国区仍需实车语义验证。
- 车辆状态只有全部项目明确正常才 ALL GOOD；缺失和未知不会默认为正常。

## Health 读取

`GetHealth` 按 SERVER_STREAMING 读取首条后取消该次订阅；保留共享 Channel。截止时间 4 秒，按 VIN 缓存 5 分钟，失败退避 1 分钟；手动刷新使缓存立即过期但保留旧值供失败回退。登录/退出清空缓存。普通车况读和命令写不改成流式调用，写请求不重试。

接口依据：`idreamshen/hass-volvooncall-cn`，commit `db0e24fd4f07bb3120fa848b3491f4d8d96de92a`，`custom_components/volvooncall_cn/proto/health.proto`。这支持传输类型和字段定义，不等于中国极星实车成功证据。

## 空调

车辆分钟 + 车辆报告时间用于展示倒计时；超过一分钟的推算明确标估算。0 分钟/推算到期提示刷新，不改真实开关状态。不因显示倒计时触发远控。车辆分钟缺失时，只有本 App 已确认刚启动才有 30 分钟本机回退。

## Widget 和运行开销

实际 Launcher 尺寸、系统字号决定布局；最小尺寸仍保留更新时间与 48dp 主控制触区。部分字段容纳不下时显示 +N，放大组件后恢复更多字段。透明/模拟磨砂、独立中英文、原 VI 字体资源保留，新增文字颜色选项。

每批更新复用一个快照，底图为 2MiB 上限缓存；滑块松手更新。首页定时显示更新不重建控件，无新增后台分钟轮询或 WakeLock；环境光在不可见、省电或关闭动画时停止。

## 签名

新增显式签名环境变量与可选 GitHub Secrets 构建路径，不向源码提交私钥。CI 缺少固定签名时仅为 Debug 验证产物。不同证书不能直接覆盖升级，参见更新说明的已检查指纹；不建议通过卸载绕过。


已确认用户安装 v0.7.5 GitHub Actions APK。该 CI 私钥未持久保存，不能从 APK 恢复。因此另加 preview 构建类型：包名后缀 .preview、独立应用/Widget 名称、同功能代码、保留签名；与原版并行安装并单独登录。默认 Release 原包名不变，不卸载、不迁移旧私有数据。
