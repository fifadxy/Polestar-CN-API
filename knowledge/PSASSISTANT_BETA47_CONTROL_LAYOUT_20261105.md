# PsAssistant v1.0.0-beta47 /161 — 净化读数与逐皮肤按钮布局

2026-11-05 · Android 主程序 UI 实验/正式布局可选配置

## 改动目标

1. **净化未运行**：主按钮不再显示「已关闭」或 Off，默认显示车辆实际上报的 AQI 与 PM2.5。缺失值使用 --，不使用虚构空气质量数据。发送中/待确认、正在运行的倒计时优先级不变；用户手动设为隐藏时尊重隐藏配置。
2. **按钮视觉微调**：七种皮肤（`simple`,`detailed`,`volike_polestar`,`niolike`,`niolike2`,`ps_default`,`simple2`）的八类首页操作（门锁、空调、净化、尾箱、车窗、寻车、露营、保养）各自保存独立视觉参数。
3. **每个按钮十个属性**：宽度比例 60–100%、高度比例 60–100%、边框线条 0–6dp、圆角 0–28dp、图标 50–190%、文字 60–180%、按钮位置 X/Y ±24dp、图文焦点 X/Y ±24dp。默认不写入任何设置，**继续使用原版布局和配色**。
4. **离线实时预览和分项恢复**：在 `设置 → 外观与交互 → 各皮肤按钮布局` 先选皮肤、再选按钮，在同一窗口实时预览；按保存才写入偏好；单项复原或重置该皮肤的所有按钮，不改变其他皮肤。
5. **响应边界**：各按钮仍处在既有权重网格的独立 FrameLayout 容器中，外框宽高及位置自动夹紧到原来分配的槽位。点击事件仍绑定在实际按钮控件上，调整焦点只平移视觉内容，不扩大触发远程控车的区域。
6. **适配现有整体字号和极简模式**：global 字体/图标参数作为乘数叠加；极简文字隐藏逻辑保持现状；多行净化指标在紧凑布局中使用固定上限显示。
7. **安全/数据**：不改 API、Token、LSPosed、OPPO CarLink、流体云、托管和远控的授权/回读逻辑；布局预览没有任何云端请求，所有新设置进入白名单 JSON 备份/恢复。

## 实施范围

`SkinButtonLayout.java`（per-skin per-control 存储、尺寸约束、图文焦点、绘图预览）、`MainActivity.java`（净化展示、控件包装、外观设置页）、`ButtonFeedback.java`（空闲空气质量）、`CenteredStatusButton.java`（局部比例与焦点）、`SettingsBackup.java`（新键白名单与容量）、`button_appearance_ids.xml`、`UpdateHistoryActivity.java`及 JUnit/Robolectric 测试。

## 验收

- 门锁/空调/净化/尾箱在 PS 默认、NIO、VoLike、Simple2 等首页没有相互遮挡；旧参数、极简以及 16/17 系统字体放大仍能显示。
- 净化关闭时显示 AQI/PM2.5，上报为空则显示 --；不出现「已关闭」，运行中仍显示剩余时间/确认状态。
- 切换皮肤后其它皮肤已保存的参数不变；备份和恢复能恢复新参数；恢复本皮肤和恢复单个按钮不影响其他按钮。
- 设置实时预览没有网络请求、车辆控制或其他副作用。
- Java 编译、Lint、应用/Bridge 自动化测试和真机界面截图按设备分辨率验证。

当前 CI 若产出 `VALIDATION-debug.apk`，不代表独立登录签名 FULL；真正 FULL 仍需复用授权签名配置并做同证书验证。真实车辆操作须通过原有命令结果回读。
