# PsAssistant 1.2.0 / 165 · 账号安全与稳定性正式版
2026-11-09 · Main Android · 方案按用户最终确认实施

## 版本与范围
- 主程序：`1.2.0`、`versionCode 165`、包名 `io.github.polestarcn.companion` 不变。
- **OPPO Bridge 2.6.0 /39 完全不修改：** `android-app/oppoBridge/**`、LSPosed Hook、CarLink 协议、原生卡片适配及 OEM SDK 门禁均保持原有文件；本版独立改进主 App 和账号安全。
- 维持已有中国区登录 API、会话加密、安全车控回读、Widget 选择与现有 UI/皮肤。

## 1. 自愿保存登录密码
| 条件 | 规则 |
|---|---|
| 默认设置 | `remember_credentials_optin=off`，从不在未同意时保存密码 |
| 用户授权 | 登录前勾选“记住账号和密码”；**登录成功后**要求系统身份验证，通过才写入 |
| 密码保护 | Android Keystore 独立别名 `psa_cn_user_auth_aes_256_v1`、AES-256-GCM、随机12字节 IV、128位认证标签、域隔离 AAD |
| 设备身份验证 | SDK30+ 强生物识别或系统锁屏凭据；老版本要求强生物识别；Keystore 60 秒系统授权窗口，每次读取仍需系统提示 |
| 数据位置 | App 私有 `psa_cn_saved_login_v1`，手机号与密码共同在加密信封里，绝不在普通 SharedPreferences 明文缓存 |
| 会话隔离 | 现有 `SecureSessionStore` 继续独立保存 Access/Refresh Token；两者**不能共用密钥** |
| 导出隔离 | `SettingsBackup` 白名单不包含密码/Token/凭据；`allowBackup=false`，云备份/设备转移排除 SharedPreferences |
| 清除机制 | 单独删除密码不退出当前登录；“退出并清除所有登录数据”同时清除 Token 和密码专用密钥 |
| Root 风险 | Root、Magisk、LSPosed 可攻击运行时，Keystore 无法完全防止具有高级权限的代码在请求期间观察明文；不作不实保证 |

密码只在网络登录请求和用户主动解密的短时过程中出现；Activity 重建/停止时不将密码复制到保存字段。Android 的 String 与 HTTP 序列化有不可完全清零的堆副本，不宣称零暴露。

## 2. 一键重新登录
- 已存储加密凭据时，未登录页面显示“一键重新登录”；设置 → 账号与安全同样提供入口。
- 用户确认后必须通过指纹/设备锁屏验证；本机进程解密 -> **原中国区真实登录接口** -> 成功后建立新 Session。
- 无保存凭据、不具备 FULL 客户端资源、设备验证不可用时明确提示手动登录，不使用 Mock 响应。
- 远程指令正在发送/等待回读、普通车况刷新进行中或露营托管正在运行/停止核实中：**不允许重新登录**，避免中途切换鉴权上下文。
- 显式退出时，`sessionGeneration` 废止旧登录结果；API 级 `sessionEpoch` 拒绝旧 OAuth Token 刷新覆盖新会话，含登录期间启动的异步请求。
- 相同手机号重新认证保留可用车辆选择；切换到不同账号则清除旧选择/缓存，强制重新发现授权车辆。
- Token 仍正常且只需更新车况时，请使用“重新验证当前 Session 和车辆车况”，不调用保存的密码。**不会自动在后台反复使用密码**。

## 3. UI 与状态管理
- 登录页：手机号、密码、显示/隐藏、明确的“记住密码”勾选框、登录按钮、已保存账户的受保护一键登录。
- 防止输入焦点丢失：登录过程中更新状态文字与按钮，不因数据刷新重建输入表单。
- 登录密码输入框关闭 View 状态恢复和系统自动填充；页面销毁、后台切换时清除输入内容及待保存的 char[]。
- 设置 → “账号与安全、诊断与关于”：会话状态、加密凭据状态、下次登录保存选项、一键登录、Session 验证、单独删密码、退出并全清。
- 退出只清空当前 Token，保留用户此前**主动选择**保存的加密账号；专用全清入口可以一起删除。

## 4. 效率与诊断
- Widget 未安装时跳过全部车况反序列化/绘制路径，避免无意义的工作。
- 使用既有按变更数据绑定与分组 TTL；不修改远控回读规则或 OPPO 原生刷新。
- 新增仅在当前进程保留的请求统计：普通/分组车况及登录成功/失败次数、平均耗时；**不记录手机号、VIN、Token、请求体或用户身份**。
- 诊断日志对敏感键值脱敏，限制单条长度及换行；设置里可查看安全聚合报告，导出时带有清晰标识。
- 由于没有相同机型的真实耗电采样，不承诺明确百分比的 CPU/电池节省；需实机验证。

## 5. 验收标准
1. 无勾选：仅持久化现有 Session，凭据库为空；登录失败不写入密码。
2. 勾选后真实登录成功：弹出系统身份验证，取消不存储；同意后仅存在 AES-GCM 密文。
3. 密文随机 IV、AAD、标签破坏验证，密钥不一致或损坏立即拒绝解密。
4. 已保存凭据可一键重新登录；没有凭据或登录配置缺失时不能假成功。
5. 验证退出/重新登录竞态：旧 API 回调不得在新会话下恢复旧 token 或渲染成功。
6. 车控、托管关键状态期间重登被拒绝，不发送重复车辆指令。
7. 仅删除密码不影响现有 Token；全清操作删除两者；设置备份不包含任何敏感材料。
8. 既有 UI/Widget/OPPO 桥接回归、Android Debug 编译、Lint、APK 体积及完整单元测试通过。
9. **正式 FULL 包**使用历史同一签名和经许可的私有中国区兼容资源；通过签名、版本码、非调试、ZIP、资源校验；真机手机号登录与远控单独验收。
