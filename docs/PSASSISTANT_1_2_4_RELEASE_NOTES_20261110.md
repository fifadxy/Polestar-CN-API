# PsAssistant 1.2.4 — 行驶与能耗费用统计

2026-11-10 · `versionName 1.2.4` · `versionCode 169`

## 主要更新

| 功能 | 新增 / 调整 |
|---|---|
| 统一名称 | 主菜单、车况弹窗、能耗详情统一为 **行驶与能耗费用统计**；四个图表切换项固定为 **行驶能耗 / 驻车空调 / 行驶里程 / 能耗费**。 |
| 数据日期 | 最近 **3 / 7 / 31 天**、自定义起止年月日。自定义日期提供两端的日历选择，以及开始日期 ±1/3/6 个月和结束日期 ±1 个月快捷操作。 |
| 图表跨度 | 按**天 / 周 / 月**汇总，支持 **柱状 / 波浪曲线 / 叠加**三种视图，继续采用 VI 橙色；不连线跨越无采样区间。 |
| 趋势对比 | 图表顶部的 VI 橙色百分比可点击循环切换 **对比前7天 / 前31天 / 前3天 / 不显示**，比较紧接当前日期之前的等长区间；同比基数无效则显示采样不足而非虚构百分比。 |
| 里程趋势 | 点击“行驶里程”显示本机采样里程的日/周/月趋势；另显示**近7日采样里程 / 选定区间日均 / 折算月均**。均值是对本机有效里程增量的区间换算，不代表完整计量里程。 |
| 试验背景 | 原地图背景试验设置中新增能耗/里程图背景：可选 **行驶能耗、驻车空调、行驶里程、能耗费**及柱状、曲线、叠加与日/周/月。后台只读取本机最近31天已保存的记录，无历史不画假图，不触发车辆刷新；地图、图片与能耗背景互斥。 |
| Widget 时间 | Widget 底部更新时间默认为 **月-日 时:分**（如 `11-10 09:12`），新增预设及受校验的自定义日期格式；小尺寸优先去除“更新”前缀而保留日期。 |
| 车况顶视 | 门窗和胎压等车况二级菜单跟随当前日间/夜间主题自动使用白色/黑色顶视图；不再使用旧高清白车顶视图，不改主页独立选图。 |
| 停车位置 | 点击首页车辆定位直接打开大面积（竖屏高度约88%弹窗）、可拖动／缩放的**高德官方交互地图**，不再先显示缩略图再打开三级地图；弹窗内提供 ＋／－、回到车辆、更新停车点、可选手机定位和刷新。刷新在当前弹窗内更新，不另弹新窗；不申请高德 Key。 |

## 数据与安全

- TM 行驶电量与费用均为车辆上报 TM 行程里程 × TM 平均能耗 × 用户设置电价的估算；TA 费用沿用 TM 均耗做参考，不等于实际充电账单。
- 历史记录仅使用本机有效采样；数据库结构不变，原有历史范围与本地设置兼容；自定义日期超出保留范围或结束早于开始时拒绝查询。
- Widget 日期仅改变显示格式，不修改车辆原始更新时间。
- **不更改**中国区独立登录、车控 RPC、OPPO Bridge 或 LSPosed/Hook 源码，不上传私有客户端资源、令牌或签名文件到 GitHub。
- GitHub Actions 产生无私有登录资源的 VALIDATION APK；独立登录兼容包需要以已批准的原资源和历史证书离线封装并完成 APK 签名验证。真机登录和远控仍须设备验收。

- 停车定位弹窗内可直接交互浏览地图；“打开地图”保留为底部小按钮，仅在需要调用外部地图 App 时使用，二级菜单无需经过三级窗口。
